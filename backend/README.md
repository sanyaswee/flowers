# Backend Server
The server for handling data and controlling the nodes.

## HTTP Documentation (Swagger / openapi)
The documentation is available on [localhost:3000/docs](localhost:3000/docs)

### Note
The documentation was automatically generated by [utoipa](https://github.com/juhaku/utoipa), based on comments, structs and datatypes, thats why the values in example responses may be weird

## Requirements
You should have the MQTT broker like `mosquitto` to be running

### Debian/Ubuntu
```
sudo apt update
sudo apt install mosquitto-clients
```
Then you should update the config file:
```
sudo nano /etc/mosquitto/conf.d/local.conf
```
Add these lines:
```
listener 1883 0.0.0.0
allow_anonymous true
```
And finally:
```
sudo systemctl restart mosquitto
sudo ufw allow 1883
```

## Running
After all requirements have been satisfied:
```
cargo run --release
```

### SQLite note
Due to relative sqlite paths, there is a difference between `cargo run -p backend` from project root and `cargo run` here. See [#12](https://github.com/sanyaswee/flowers/issues/12)
